### IPC Channel Naming Convention

Use namespaced `domain:action` format:

| Prefix | Purpose | Examples |
|--------|---------|----------|
| `config:*` | Configuration operations | `config:get`, `config:init`, `config:setLanguage` |
| `theme:*` | Theme operations | `theme:get`, `theme:set` |
| `license:*` | License operations | `license:activate`, `license:deactivate` |
| `trial:*` | Trial operations | `trial:getStatus`, `trial:shouldShowReminder` |
| `ui:*` | UI interactions | `ui:toast`, `ui:focusSearch` |
| `window:*` | Window operations | `window:minimize`, `window:close` |
| `shell:*` | Shell operations | `shell:openExternal` |
| `[domain]:*` | App-specific domains | `phrases:*`, `database:*`, `backup:*` |
